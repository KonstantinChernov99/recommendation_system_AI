# Рекомендательная система реального времени. Проект 1 курса магистратуры ИИ НИУ ВШЭ

Интеллектуальная рекомендательная система реального времени

О проекте

Добро пожаловать в репозиторий годового проекта по разработке современной рекомендательной системы.

Главная цель проекта — создание гибкой и высокопроизводительной рекомендательной системы для сайта или мобильного приложения компании, способной рассчитывать персональные рекомендации «на лету» на основе истории покупок, сессионной активности и характеристик товаров.

Архитектура и ключевые задачи

1. Проект охватывает полный цикл разработки ML-системы: от первичного анализа данных и моделирования до развертывания интерактивного веб-сервиса.
2. Сбор и подготовка данных: поиск, анализ и предварительная обработка датасетов, содержащих ID клиентов, временные метки покупок, ID товаров, а также детальные метаданные и характеристики ассортимента.
3. Сессионные и последовательные рекомендации (Sequence Signals): учет динамических паттернов поведения пользователя в реальном времени для предсказания следующего шага или покупки.
4. Item-to-Item рекомендации: построение связей между похожими товарами на основе коллаборативной фильтрации и эмбеддингов.
5. Семантический поиск и RAG-подходы: интеграция методов Retrieval-Augmented Generation и векторного поиска по характеристикам товаров для глубокого понимания контекста запросов.
6. Гибридизация и ансамблирование (Blending): интеллектуальное смешивание различных рекомендательных алгоритмов для достижения оптимального баланса точности и разнообразия.
7. Диверсификация выдачи (MMR): применение алгоритма Maximal Marginal Relevance (MMR) для избежания однотипности в рекомендациях и максимизации полезности выдачи.
8. Офлайн и онлайн контуры: проектирование архитектуры для пакетной офлайн-генерации фичей и инференса рекомендаций в реальном времени (онлайн-контур).

Метрики качества
nDCG@K (Normalized Discounted Cumulative Gain) — оценка качества ранжирования релевантных товаров.
Recall@K — оценка полноты охвата предпочтений пользователя.

Демонстрационный сервис
Для демонстрации работы алгоритмов в интерактивном режиме разработан веб-интерфейс на базе Streamlit. Он позволяет в режиме реального времени тестировать генерацию рекомендаций, настраивать параметры смешивания и оценивать выдачу системы.
